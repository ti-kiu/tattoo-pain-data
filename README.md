# Tattoo Placement Pain Data

Open dataset: tattoo placement pain levels (scale of 10) and healing times for 7 common body areas.

## Quick view

| Placement | Pain (of 10) | Healing (weeks) |
|-----------|-------------|-----------------|
| forearm | 2-4 | 2-4 |
| shoulder | 3-5 | 2-4 |
| thigh | 4-6 | 2-4 |
| wrist | 4-7 | 2-4 |
| back | 5-7 | 2-4 |
| ankle | 5-7 | 2-4 |
| ribs | 7-9 | 4-8 |

## Files

- [`tattoo-pain.csv`](tattoo-pain.csv) — CSV format
- [`tattoo-pain.json`](tattoo-pain.json) — JSON format

## Method

Pain levels compiled from publicly available tattoo artist and community consensus guides, aggregated across 7 body placement areas. Healing times are general estimates; individual healing varies.
